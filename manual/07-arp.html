Arpeggiator

押さえた和音を捌くだけの機能ではありません。スケール・コード進行・パターンのつなぎ替えまで持つので、 和音を HOLD しておけば曲が回ります。

More than a note-shuffler. With scales, chord progressions, and pattern chaining, you can hold one chord and let a whole song run over it.

SCALE / KEY

操作子Control 内容What it does
KEY主音です。C 〜 B の 12 音から選べます。Root note, C through B.
SCALE MAJOR · MINOR · DORIAN · PHRYGIAN · MIXOLYD · HARM MIN · PENTA MAJ · PENTA MIN · CHROMATIC
SCALE LOCK / FREE LOCK は鍵盤で押した音をスケール上へ寄せます。FREE はそのまま鳴らします。 LOCK snaps what you play to the scale. FREE lets any note through.

CHORD

和音を自分で押さえ続けなくても、コード進行を組んでおけば ARP がその上を走ります。

Instead of holding a chord yourself, write a progression and let the arpeggiator run over it.

操作子Control 内容What it does
OFF / AUTO / MANUAL OFF は鍵盤で押した音だけを使います。AUTO は小節数に従って自動で進み、MANUAL は NEXT ▶ を押したときだけ進みます。 OFF uses only what you play. AUTO advances by bar count. MANUAL advances only when you press NEXT ▶.
スロットSlots 最大 8 個です。+ SLOT / − SLOT で増減し、スロットをタップすると編集欄が開きます。 Up to 8. Use + SLOT / − SLOT, and tap a slot to open its editor.
DEGREE スケール上の度数です。1 maj 6 min のように、番号と性質で表示します。 Scale degree, shown as number plus quality — 1 maj, 6 min.
BARSそのコードを鳴らす小節数です。1 〜 4 で指定します。How many bars the chord lasts, 1 – 4.
TRIAD / 7TH / SUS4 / +OCT 和音の積み方です。3 和音 / 7th 入り / sus4 / オクターブ足しから選べます。 Chord voicing: triad, seventh, suspended fourth, or with the octave added.

LAYER

ARP は 2 系統あります。I LEAD と II BASS で、それぞれ独立したパターン・速さ・音域を持ちます。 タブの操作はすべて選んでいる側のレイヤーに効きます。

There are two arpeggiators, I LEAD and II BASS, each with its own pattern, rate, and range. Everything on this tab applies to whichever layer is selected.

初期状態で動いているのは I だけです。II を使うには、II を選んでから LAYER ON を押してください。

Only layer I runs by default. To use II, select it and press LAYER ON.

PATTERN

操作子Control 内容What it does
A / B / C / D レイヤーごとに 4 つのパターンがあります。切り替えると編集対象も変わります。 Four patterns per layer. Switching also changes what you are editing.
COPY → 今のパターンを次のスロットへ複製します(A → B → C → D → A)。 Duplicates the current pattern into the next slot (A → B → C → D → A).
CHAIN パターンを順につないで流します。最大 8 リンクです。リンクをタップで A〜D が巡回し、 ダブルタップで小節数(1 / 2 / 4 / 8)が巡回します。 Plays patterns back to back, up to 8 links. Tap a link to cycle A–D, double-tap to cycle its bar count (1 / 2 / 4 / 8).

STEPS

16 個のマスがパターンの 1 周分です。タップするたびに値が巡回します。編集する内容は 3 ページに分かれています。

Sixteen cells make one pass of the pattern. Each tap cycles the value. Three pages of editing:

ページPage タップで巡回する値Tap cycles through
GATE 鳴らさない → 鳴らす(●)→ 強く鳴らす(A) Off → on (●) → accent (A)
OCT −1 → 0 → +1 → +2 のオクターブ移動 Octave offset: −1 → 0 → +1 → +2
PITCH スケール上の音を 1 つずつ固定していきます。一周すると解除され、 そのステップは動きの規則(MOTION)に戻ります。 Pins a specific scale note, stepping up one at a time. Cycle past the top to clear it, and that step returns to the MOTION rule.

ALL ON は全ステップを鳴らす状態に、CLEAR はそのページの値を消します。 🎲 RANDOMIZE は鳴らすステップにランダムな音程を割り当てて PITCH ページへ切り替えます。 ランダムといってもその場で固定されるので、気に入った並びをそのまま手直しできます。

ALL ON turns every step on; CLEAR wipes the current page. 🎲 RANDOMIZE assigns random pitches to the active steps and jumps to the PITCH page. The result is pinned, not re-rolled each pass, so you can keep a phrase you like and edit it by hand.

MOTION

操作子Control 内容What it does
UP / DOWN / UP-DN 和音を下から / 上から / 往復で捌きます。 Runs the chord upward, downward, or back and forth.
RANDOM / AS PLAYED / CHORD 毎回ランダム / 押した順 / 全音を同時に鳴らす、から選べます。 Random each time, in the order you pressed, or all notes together.
1/8 · 1/16 · 1/16T · 1/32 刻みの細かさです。T は 3 連を表します。Step rate. T means triplets.
LEVELそのレイヤーの音量です。Level of this layer.
STEP LENGTH 1 周の長さです。1 〜 16 で、16 より短くすると変拍子になります。 Pattern length, 1 – 16. Set it below 16 for odd meters.
GATE·L × SWING 固定帯の枠です。X が音の長さ(レイヤーごと)、Y がハネ(全体共通)です。 軸名の ·L は「レイヤーごと」の印です。 Fixed strip. X is note length (per layer), Y is swing (global). The ·L marks a per-layer parameter.
RANGE·L × OFFSET·L 固定帯の枠です。X が何オクターブに広げるか(1 〜 4)、Y が全体の移調(−3 〜 +1)です。 Fixed strip. X is octave span (1 – 4), Y is octave offset (−3 to +1).

鍵盤の音が持続するのは、ARP I が止まっていてコード進行も OFF のときだけです。 どちらかが動いていると、鍵盤は ARP に音を渡す入口として働きます。

Keyboard notes only sustain when arpeggiator I is off and the chord progression is OFF. Otherwise the keyboard acts as an input that feeds notes to the arpeggiator.
